# FrankieResumeAI

This repository contains the FrankieResumeAI project — a NextJS starter adapted for resume generation and management.

To get started, take a look at src/app/page.tsx.

## Database setup

The resume API currently stores drafts and versions in PostgreSQL. Configure `POSTGRES_URL` and create the required tables before using resume persistence or generation. Follow the [database setup guide](docs/database-setup.md).
